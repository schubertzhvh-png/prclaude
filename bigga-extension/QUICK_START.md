# 🚀 BIGGA v2.0 - Быстрый старт

## 📦 Установка (5 минут)

### Шаг 1: Создай иконки

**Самый быстрый способ** - используй эмодзи как иконку:

1. Открой https://favicon.io/emoji-favicons/dart/
2. Скачай ZIP
3. Переименуй файлы:
   - `android-chrome-512x512.png` → `icon128.png`
   - `favicon-32x32.png` → `icon48.png`
   - `favicon-16x16.png` → `icon16.png`
4. Скопируй в папку `bigga-extension/icons/`

Или используй любые 3 PNG картинки (16x16, 48x48, 128x128).

### Шаг 2: Загрузи в Chrome

1. Открой **Chrome** → `chrome://extensions/`

2. Включи **"Режим разработчика"** (Developer mode) в правом верхнем углу

3. Нажми **"Загрузить распакованное расширение"** (Load unpacked)

4. Выбери папку `bigga-extension`

5. ✅ Расширение установлено!

### Шаг 3: Закрепи расширение

1. Нажми на иконку пазла в Chrome
2. Найди **BIGGA v2.0**
3. Нажми на кнопку pin (📌)

## 🎮 Первый запуск

### 1. Зайди на Axiome

Открой https://axiome.io

Должно появиться в консоли (F12):
```
🎯 BIGGA v2.0 loaded on Axiome
🚀 Initializing BIGGA v2.0...
🔍 Found X token cards on Axiome
✅ BIGGA v2.0 initialized
```

### 2. Настрой цвета

Нажми на иконку BIGGA → вкладка **🎨 Colors**:

**Пример настройки:**
- Market Cap ≥ $10,000 → 🟡 Жёлтый
- Market Cap ≥ $15,000 → 🔵 Синий
- Market Cap ≥ $20,000 → 🔴 Красный

Нажми **"Save Colors"**.

Эти историки будут **всегда** подсвечены.

### 4. Просматривай токены

Возвращайся на Axiome и смотри как расширение:
- ✅ Подсвечивает карточки токенов

- ✅ Отображает статистику (фолловеры, количество токенов, средний MC)

## 📊 Что означают цифры?

### Historian Badge (бейдж на карточке)

```
👤 @username (10.5K followers)   ← Имя и фолловеры
📊 Tokens posted: 15              ← Сколько токенов запостил
📈 Last 3 avg: $25K MC            ← Средний MC последних 3 токенов
```

### Что такое "Last 3 Tokens Avg"?

Это **средний Market Cap последних 3 токенов** этого историка.

**Почему это важно?**
- Показывает текущую "форму" историка
- Недавние токены важнее старых
- Если Last 3 высокий = историк "в огне" 🔥

**Пример:**
- Историк запостил 10 токенов
- Последние 3: $30K, $20K, $25K
- Last 3 avg = **$25K**
- Он попадает под правило "≥ $20K" → 🔴 Красная подсветка

## 🎯 Как работает логика?

### Приоритет подсветки:

1. **WhiteList** → Твой цвет (например 🟢 зелёный)
2. **Color Rules** → Цвет по правилу (🟡🔵🔴)
3. **Нет правила** → Без подсветки

### Пример:

```javascript
@cryptoking:
  Last 3 avg = $22K
  В WhiteList? Нет
  Правила:
    ≥ $20K → 🔴 Красный ✅
    ≥ $15K → 🔵 Синий
    ≥ $10K → 🟡 Жёлтый

  Результат: 🔴 Красная подсветка
```

```javascript
@megawhale:
  Last 3 avg = $12K
  В WhiteList? Да ⭐

  Результат: 🟢 Зелёная подсветка (WhiteList приоритет!)
```

## 🔍 Сбор данных

### Автоматический процесс:

1. Расширение видит новый токен на Axiome
2. Извлекает ссылку на Twitter из карточки
3. Скрейпит профиль через **Nitter** (без API!)
4. Сохраняет данные:
   - Username
   - Фолловеры
   - Данные токена (адрес, название, тикер)
5. Рассчитывает средние значения MC
6. Применяет подсветку

### Где хранятся данные?

Всё в **IndexedDB** в твоём браузере:
- Chrome DevTools → Application → IndexedDB → BiggaDB

**3 таблицы:**
- **historians** - Данные историков
- **tokens** - Токены с адресами
- **cache** - Кэш для скрейпинга

## 🐛 Проблемы?

### Расширение не работает

1. Открой `chrome://extensions/`
2. Проверь что BIGGA включён
3. Перезагрузи расширение (кнопка 🔄)
4. Проверь ошибки в консоли (F12)

### Карточки не подсвечиваются

1. F12 → Console
2. Должно быть: `✅ BIGGA v2.0 initialized`
3. Должно быть: `🔍 Found X token cards`
4. Если нет → селекторы не подходят под Axiome

### Twitter скрейпинг не работает

1. Nitter может быть недоступен
2. Проверь Network tab в DevTools
3. Расширение попробует fallback на прямой Twitter

### База данных пустая

1. DevTools → Application → IndexedDB → BiggaDB
2. Если нет таблиц:
   - Удали расширение
   - Переустанови
   - База создастся автоматически

## 💡 Советы

### 1. Настрой агрессивные фильтры

```
≥ $50K → 🟣 Фиолетовый (супер перспективные)
≥ $30K → 🔴 Красный (хорошие)
≥ $15K → 🔵 Синий (средние)
≥ $5K  → 🟡 Жёлтый (новички)
```

### 2. Используй WhiteList активно

Добавляй историков которые:
- Консистентно дают $20K+
- Имеют хороший track record
- Быстро реагируют на тренды

### 3. Экспортируй данные регулярно

- Раз в неделю делай backup
- Анализируй в Excel
- Находи паттерны

### 4. Мониторь Last 3, а не Average

**Average MC** = все токены (включая старые)
**Last 3 avg** = только последние 3 (текущая форма)

Last 3 важнее! 🔥
