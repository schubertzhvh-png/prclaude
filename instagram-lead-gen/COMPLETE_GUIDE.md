# Instagram Lead Generator - Полное руководство

Полноценная система для автоматизации лидогенерации в Instagram с Chrome расширением и веб-дашбордом.

---

## 🎯 Что это?

**Два инструмента в одном:**

### 1. Chrome Extension (Расширение)
- Парсинг лидов прямо из Instagram
- Автоматическая отправка сообщений
- Работает в фоне
- Локальное хранилище

### 2. Web Dashboard (Веб-дашборд)
- Красивый интерфейс для управления
- Статистика и аналитика
- Удобная работа с данными
- Современный дизайн

**Они работают вместе** - расширение собирает данные, дашборд их отображает!

## 🚀 Быстрый старт (10 минут)

### Шаг 1: Установить расширение (5 минут)

```bash
1. Откройте Chrome
2. chrome://extensions/
3. Включите "Developer mode"
4. "Load unpacked" → выберите папку instagram-lead-gen
5. Готово! ✅
```

**Создать иконки:**
```bash
Откройте icons/generate-icons.html → скачайте 3 иконки
```

### Шаг 2: Открыть веб-дашборд (1 минута)

```bash
# Вариант 1: Просто откройте файл
Двойной клик на web-dashboard/index.html

# Вариант 2: Локальный сервер
cd web-dashboard
python3 -m http.server 8000
# Откройте http://localhost:8000
```

### Шаг 3: Первый тест (4 минуты)

```bash
1. Откройте Instagram в Chrome
2. Перейдите на любой профиль
3. Кликните на расширение
4. Scraper → Followers → Start
5. Подождите 30 секунд
6. Leads → посмотрите собранные профили
7. Откройте веб-дашборд → увидите те же данные!
```

**Готово!** 🎉

## ⚙️ Настройки

### Rate Limiting (важно!)

**Безопасные лимиты:**
```
Messages per hour: 15-20
Messages per day: 80-100
Start time: 09:00
End time: 21:00
```

**Для новых аккаунтов (warmup):**
```
День 1-2: 5-10 сообщений/день
День 3-5: 20-30 сообщений/день
Неделя 2+: 50-80 сообщений/день
```

### AI Generation (опционально)

**Получить API ключ:**
```
1. https://platform.openai.com/api-keys
2. Create new secret key
3. Скопировать ключ
```

**Настроить:**
```
Settings → OpenAI API Key → вставить → Save
```

**Использовать:**
```
В сообщении: {ai} Напиши дружелюбное сообщение
```

## 🛡️ Безопасность

### Имитация человека

**Что делается:**
- Случайные задержки (30-100мс между символами)
- Варьирующиеся паузы между действиями
- Работа только в активные часы
- Соблюдение rate limits

**Warmup режим:**
```
Новый аккаунт → начать с 5 сообщений/день
Постепенно увеличивать
Через 1-2 недели → нормальные лимиты
```

### Риски

**Instagram может:**
- Ограничить отправку сообщений
- Временно заблокировать аккаунт
- Потребовать подтверждение

**Как избежать:**
- Не превышать лимиты
- Делать перерывы
- Использовать warmup
- Разнообразить тексты
- Не парсить слишком быстро

### Хранение данных

**Локально:**
- Chrome Storage (расширение)
- LocalStorage (дашборд)
- Не отправляется на сервер
- Доступно только вам

**OpenAI API ключ:**
- Хранится локально
- Используется только для OpenAI
- Можно удалить в любой момент

## 🔧 Troubleshooting

### Расширение не работает

**Проблема:** Расширение не отображается
```
Решение:
1. chrome://extensions/
2. Проверить что включено
3. Developer mode ON
4. Reload extension
```

**Проблема:** Парсинг не запускается
```
Решение:
1. Убедитесь что на странице Instagram
2. Залогинены в аккаунт
3. Обновите страницу
4. Попробуйте снова
```

### Дашборд не работает

**Проблема:** Extension: Disconnected
```
Это нормально! Дашборд работает и без расширения.
Для полного функционала нажмите "Sync".
```

**Проблема:** Данные не синхронизируются
```
Решение:
1. Нажмите "🔄 Sync"
2. Проверьте что расширение установлено
3. Откройте консоль (F12) на ошибки
```

### AI не работает

**Проблема:** AI генерация не работает
```
Решение:
1. Проверьте API ключ (Settings)
2. Убедитесь что есть баланс на OpenAI
3. Проверьте интернет
4. Посмотрите консоль на ошибки
```
