# Quick Start - Instagram Lead Generator

## Быстрая установка (5 минут)

### 1. Создайте иконки

Откройте файл `icons/generate-icons.html` в браузере и скачайте все три иконки:
- Кликните "Download 16x16"
- Кликните "Download 48x48"
- Кликните "Download 128x128"

Переместите скачанные файлы в папку `icons/`.

### 2. Установите расширение

1. Откройте Chrome
2. Перейдите в `chrome://extensions/`
3. Включите "Developer mode" (переключатель вверху справа)
4. Нажмите "Load unpacked"
5. Выберите папку `instagram-lead-gen`

✅ Расширение установлено!

### 3. Первый запуск

1. Откройте Instagram и войдите в аккаунт
2. Кликните на иконку расширения в панели Chrome
3. Готово! Можете начинать.

## Первый тест

### Собрать лиды (2 минуты)

1. Откройте профиль любого Instagram аккаунта
2. Кликните на расширение
3. Вкладка "Scraper" → выберите "Followers"
4. Введите username (или оставьте пустым для текущего профиля)
5. Нажмите "Start Scraping"

Расширение начнет собирать подписчиков. Остановите через 20-30 секунд.

### Проверить лиды

1. Вкладка "Leads"
2. Вы увидите собранные профили
3. Можете экспортировать в CSV

### Создать кампанию (3 минуты)

1. Вкладка "Campaigns" → "+ New Campaign"
2. Название: "Тест"
3. Target: "All Leads"
4. Сообщение 1:
   ```
   Привет {firstName}! Увидел твой профиль, хотел пообщаться. Чем занимаешься?
   ```
5. Нажмите "Create Campaign"

### Запустить кампанию

⚠️ **Важно**: Начните с ОДНОГО сообщения для теста!

1. Найдите вашу кампанию
2. Нажмите "Start"
3. Расширение отправит первое сообщение

Если всё работает - добавьте больше шагов в последовательность.

## Безопасные настройки

Перейдите в Settings и установите:

```
Messages per hour: 15
Messages per day: 50
Start time: 09:00
End time: 21:00
Stop on reply: ✓
```

## Использование AI (опционально)

1. Получите API key: https://platform.openai.com/api-keys
2. Settings → вставьте ключ
3. В сообщениях используйте: `{ai} Напиши дружелюбное сообщение про сотрудничество`

## Важные советы

### ✅ Делайте:
- Начинайте с малых объемов (5-10 сообщений/день)
- Персонализируйте сообщения
- Делайте паузы между сессиями
- Используйте разные тексты

### ❌ Не делайте:
- Не отправляйте >20 сообщений/час
- Не используйте новые аккаунты агрессивно
- Не отправляйте спам
- Не используйте один текст для всех

## Проблемы?

### Расширение не появляется
- Проверьте `chrome://extensions/`
- Убедитесь что "Developer mode" включен
- Перезагрузите Chrome

### Парсинг не работает
- Убедитесь что залогинены в Instagram
- Обновите страницу
- Проверьте консоль (F12) на ошибки

### Сообщения не отправляются
- Проверьте что не превышен лимит
- Убедитесь что активные часы (9:00-21:00)
- Попробуйте отправить одно сообщение вручную
