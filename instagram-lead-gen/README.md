# Instagram Lead Generator - MVP

Личный инструмент для автоматизации поиска лидов и отправки сообщений в Instagram.

## Функции

### 1. Lead Generation (Поиск лидов)
- ✅ Парсинг подписчиков/подписок аккаунтов
- ✅ Парсинг лайкеров постов
- ✅ Парсинг по хештегам
- ✅ Фильтрация (мин/макс подписчики, только публичные, ключевые слова)
- ✅ Экспорт в CSV

### 2. Automated Messaging (Автоматизация сообщений)
- ✅ Создание кампаний с последовательностью сообщений
- ✅ Персонализация (имя, username, био)
- ✅ AI генерация текстов (OpenAI)
- ✅ Rate limiting (15-20 сообщений/час)
- ✅ Авто-остановка при ответе
- ✅ Планирование с задержками

## Установка

### Шаг 1: Скачать код

Скачайте или клонируйте эту папку на свой компьютер.

### Шаг 2: Установить расширение в Chrome

1. Откройте Chrome
2. Перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `instagram-lead-gen`
6. Расширение установлено!

### Шаг 3: Добавить иконки (опционально)

Расширению нужны иконки. Вы можете:

**Вариант A: Создать простые иконки**

```bash
# Используйте любой онлайн-генератор иконок
```

### Шаг 4: Настроить OpenAI (опционально)

Для использования AI-генерации сообщений:

1. Получите API ключ на https://platform.openai.com/api-keys
2. Откройте расширение
3. Перейдите в Settings
4. Вставьте ваш API ключ
5. Сохраните

## Использование

### Парсинг лидов

1. **Откройте Instagram** в браузере и войдите в аккаунт
2. **Откройте расширение** (кликните на иконку)
3. **Перейдите на вкладку "Scraper"**
4. **Выберите тип парсинга**:
   - Followers - подписчики аккаунта
   - Following - подписки аккаунта
   - Post Likes - лайкеры поста
   - Hashtag - посты по хештегу
5. **Введите username или URL**
6. **Настройте фильтры**:
   - Min/Max подписчиков
   - Только публичные аккаунты
   - Ключевые слова в bio
7. **Нажмите "Start Scraping"**

Расширение начнет собирать лиды. Процесс может занять время в зависимости от количества.

### Просмотр лидов

1. **Перейдите на вкладку "Leads"**
2. Вы увидите все собранные лиды
3. Можете:
   - Искать по имени/username
   - Просматривать профили
   - Удалять лиды
   - Экспортировать в CSV

### Создание кампании

1. **Перейдите на вкладку "Campaigns"**
2. **Нажмите "+ New Campaign"**
3. **Заполните форму**:
   - Название кампании
   - Выберите целевых лидов (все, по тегам, или вручную)
   - Добавьте сообщения в последовательность
   - Укажите задержки между сообщениями (в часах)
4. **Нажмите "Create Campaign"**

### Запуск кампании

1. **Убедитесь, что вы на странице Instagram**
2. **Откройте расширение**
3. **Перейдите на "Campaigns"**
4. **Найдите свою кампанию**
5. **Нажмите "Start"**

Расширение начнет автоматически отправлять сообщения с учетом ваших настроек rate limiting.

### Персонализация сообщений

В текстах сообщений можно использовать переменные:

```
{firstName} - Имя (первое слово из full name)
{username} - Username
{fullName} - Полное имя
{bio} - Био профиля
{followers} - Количество подписчиков
{ai} - Генерация AI (требуется OpenAI API key)
```

**Примеры:**

```
Привет {firstName}! Увидел твой профиль и показалось интересным. Чем занимаешься?
```

```
{ai} Напиши дружелюбное сообщение про сотрудничество
```

## Настройки

### Rate Limiting

По умолчанию:
- **15 сообщений/час** - безопасный лимит
- **80 сообщений/день** - дневной лимит
- **Активные часы**: 9:00 - 21:00

Вы можете изменить эти настройки, но будьте осторожны - слишком агрессивная отправка может привести к бану.

### Безопасность

Расширение имитирует человеческое поведение:
- Случайные задержки между действиями
- Реалистичная скорость печати
- Не отправляет ночью
- Соблюдает rate limits

### Warmup Mode (для новых аккаунтов)

Если у вас новый аккаунт Instagram, рекомендуется:

**День 1-2**: 5-10 сообщений/день
**День 3-4**: 15-20 сообщений/день
**День 5-7**: 30-50 сообщений/день
**После недели**: 80+ сообщений/день

## Экспорт/Импорт данных

### Экспорт лидов в CSV

1. Перейдите на "Leads"
2. Нажмите "Export CSV"
3. Файл сохранится с данными всех лидов

### Экспорт всех данных

1. Перейдите на "Settings"
2. Нажмите "Export All Data"
3. Сохранится JSON файл с лидами, кампаниями и настройками

### Импорт данных

1. Перейдите на "Settings"
2. Нажмите "Import Data"
3. Выберите JSON файл
4. Данные будут восстановлены

## Ограничения и риски

### Instagram ToS

Это расширение автоматизирует действия в Instagram, что технически нарушает их Terms of Service. Используйте на свой риск.

### Риск бана

При агрессивном использовании Instagram может:
- Ограничить возможность отправки сообщений
- Временно заблокировать аккаунт
- Потребовать подтверждение телефона

### Рекомендации по безопасности

1. **Не превышайте лимиты**: 15-20 сообщений/час
2. **Делайте перерывы**: не используйте 24/7
3. **Warmup для новых аккаунтов**: начинайте с малого
4. **Разнообразьте сообщения**: не используйте один и тот же текст
5. **Не парсьте слишком быстро**: делайте паузы между действиями
6. **Используйте старые аккаунты**: новые аккаунты более подвержены банам

## Troubleshooting (Решение проблем)

### Расширение не работает

1. Проверьте, что вы на странице instagram.com
2. Обновите страницу
3. Переустановите расширение
4. Проверьте консоль браузера (F12) на ошибки

### Парсинг не запускается

1. Убедитесь, что вы залогинены в Instagram
2. Проверьте, что username правильный
3. Попробуйте обновить страницу Instagram
4. Проверьте, что у вас есть права на просмотр профиля

### Сообщения не отправляются

1. Проверьте rate limits (может быть превышен лимит)
2. Убедитесь, что сейчас активные часы (9:00-21:00)
3. Проверьте, что кампания в статусе "active"
4. Попробуйте отправить одно сообщение вручную для проверки

### AI генерация не работает

1. Проверьте, что API ключ правильный
2. Убедитесь, что у вас есть баланс на OpenAI аккаунте
3. Проверьте подключение к интернету
