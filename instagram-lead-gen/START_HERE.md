# 🚀 Как запустить Instagram Lead Generator

## Шаг 1: Создать иконки (2 минуты)

### Вариант A: Генератор иконок
1. Откройте файл `icons/generate-icons.html` в браузере
2. Нажмите 3 кнопки:
   - Download 16x16
   - Download 48x48
   - Download 128x128
3. Переместите скачанные файлы в папку `icons/`

### Вариант B: Использовать любые PNG
Просто поместите 3 PNG файла (16x16, 48x48, 128x128) в папку `icons/` с названиями:
- `icon16.png`
- `icon48.png`
- `icon128.png`

---

## Шаг 2: Установить Chrome расширение (3 минуты)

1. **Откройте Chrome**

2. **Перейдите на страницу расширений:**
   ```
   chrome://extensions/
   ```
   Или: Меню → Расширения → Управление расширениями

3. **Включите режим разработчика:**
   - В правом верхнем углу найдите переключатель "Developer mode" (Режим разработчика)
   - Включите его

4. **Загрузите расширение:**
   - Нажмите кнопку "Load unpacked" (Загрузить распакованное)
   - Выберите папку `instagram-lead-gen` (та, где лежит manifest.json)
   - Нажмите "Select Folder"

5. **Проверьте:**
   - Расширение появится в списке
   - Вы увидите иконку расширения в панели Chrome (может быть в меню пазлов)
   - Закрепите иконку на панели (pin)

✅ **Расширение установлено!**

---

## Шаг 3: Открыть веб-дашборд (1 минута)

### Вариант A: Просто открыть файл (проще)

1. Перейдите в папку `web-dashboard`
2. Найдите файл `index.html`
3. **Двойной клик** по файлу - откроется в браузере

### Вариант B: Локальный сервер (рекомендуется)

**Если у вас Python:**
```bash
cd instagram-lead-gen/web-dashboard
python3 -m http.server 8000
```

Затем откройте в браузере:
```
http://localhost:8000
```

**Если у вас Node.js:**
```bash
cd instagram-lead-gen/web-dashboard
npx http-server -p 8000
```

Затем откройте:
```
http://localhost:8000
```

✅ **Дашборд открыт!**

---

## Шаг 4: Первый тест (5 минут)

### A. Проверка расширения

1. **Откройте Instagram** в Chrome: https://instagram.com
2. **Войдите** в свой аккаунт (если не залогинены)
3. **Откройте любой профиль** (например, известного блогера)
4. **Кликните на иконку расширения** в панели Chrome
5. Вы увидите popup с вкладками

**Что должно работать:**
- ✅ Popup открывается
- ✅ Видны 4 вкладки: Scraper, Leads, Campaigns, Settings
- ✅ Статистика показывает 0 лидов

### B. Проверка веб-дашборда

1. **Откройте веб-дашборд** (если еще не открыт)
2. Вы увидите красивый темный интерфейс

**Что должно работать:**
- ✅ Дашборд отображается
- ✅ Sidebar слева с навигацией
- ✅ Статистика показывает 0 лидов
- ✅ Статус расширения (может быть "Disconnected" - это нормально)

## Шаг 5: Собрать первые лиды (3 минуты)

### Через расширение (рекомендуется для первого раза):

1. **Откройте Instagram** и перейдите на любой профиль
2. **Кликните на расширение**
3. **Перейдите на вкладку "Scraper"**
4. **Настройте:**
   - Scrape Type: **Followers**
   - Username: оставьте пустым (будет парсить текущий открытый профиль)
   - Min Followers: **100**
   - Max Followers: **10000**
   - ✓ Only public accounts
5. **Нажмите "Start Scraping"**

**Что произойдет:**
- Расширение начнет собирать подписчиков
- Появится прогресс-бар
- Через 30-60 секунд остановите (кнопка "Stop")

6. **Перейдите на вкладку "Leads"**
   - Вы увидите собранные профили!

### Проверка в дашборде:

1. **Откройте веб-дашборд**
2. **Нажмите кнопку "🔄 Sync"** в правом верхнем углу
3. **Перейдите на страницу "Leads"** (sidebar слева)
4. Вы увидите ваши лиды в красивой таблице!

✅ **Работает!**

## Шаг 6: Создать кампанию (опционально)

### Создание через расширение:

1. **Расширение → Campaigns → + New Campaign**
2. **Заполните:**
   - Campaign Name: "Тестовая кампания"
   - Target: "All Leads"
   - Message 1:
     ```
     Привет {firstName}! Увидел твой профиль, хотел познакомиться. Чем занимаешься?
     ```
   - Delay: 0 hours
3. **Нажмите "Create Campaign"**

### ⚠️ Важно: НЕ запускайте кампанию сразу!

Сначала:
- Настройте безопасные лимиты в Settings
- Прочитайте про безопасность в README.md
- Протестируйте на 1-2 сообщениях вручную

## 🆘 Проблемы?

### Расширение не появилось
```
1. chrome://extensions/
2. Убедитесь что "Developer mode" включен
3. Проверьте что выбрали правильную папку (с manifest.json)
4. Попробуйте Reload расширения
```

### Дашборд не открывается
```
1. Проверьте что открыли index.html
2. Попробуйте другой браузер
3. Используйте локальный сервер (python3 -m http.server)
```

### Парсинг не работает
```
1. Убедитесь что на странице Instagram
2. Залогинены в аккаунт
3. Обновите страницу
4. Попробуйте другой профиль
```

### Extension: Disconnected в дашборде
```
Это нормально!
- Дашборд может работать автономно
- Для синхронизации нажмите "🔄 Sync"
- Или просто используйте оба инструмента параллельно
```
