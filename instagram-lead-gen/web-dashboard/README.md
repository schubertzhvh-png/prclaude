# Web Dashboard - Instagram Lead Generator

Современный веб-интерфейс для управления Instagram лидогенерацией.

## Особенности

### 📊 Dashboard Overview
- Статистика в реальном времени
- Графики и аналитика
- Быстрый доступ к последним лидам и кампаниям

### 👥 Leads Management
- Просмотр всех лидов в удобной таблице
- Поиск и фильтрация
- Экспорт в CSV
- Удаление и управление

### 📢 Campaign Manager
- Создание и управление кампаниями
- Статусы (draft, active, paused, completed)
- Запуск/остановка кампаний
- Просмотр деталей

### 🔍 Scraper Interface
- Настройка парсинга через веб-интерфейс
- Фильтры и опции
- Прогресс в реальном времени

### 📈 Analytics
- История всех сообщений
- Success rate
- Дневная статистика
- Графики производительности

### ⚙️ Settings
- Настройка rate limits
- Активные часы
- OpenAI API ключ
- Экспорт/импорт данных

## Установка и запуск

### Вариант 1: Открыть локально (рекомендуется)

Просто откройте `index.html` в браузере:

```bash
# Из папки web-dashboard
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

Или двойной клик на файл `index.html`.

### Вариант 2: Запустить локальный сервер

Для лучшей работы с расширением используйте локальный сервер:

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx http-server -p 8000
```

Затем откройте: `http://localhost:8000`

### Вариант 3: Deploy на хостинг

Можно задеплоить на:
- **Netlify**: Бесплатный статический хостинг
- **Vercel**: Быстрый deploy
- **GitHub Pages**: Прямо из репозитория
- **Firebase Hosting**: Google хостинг

## Как это работает

### Архитектура

```
index.html           # Главная страница
├── css/
│   └── style.css    # Стили (темная тема)
└── js/
    ├── storage.js   # LocalStorage управление
    ├── api.js       # Связь с Chrome Extension
    ├── components.js # UI компоненты для страниц
    └── app.js       # Главная логика приложения
```

### Связь с расширением

Веб-дашборд может работать в двух режимах:

#### 1. Standalone режим (без расширения)
- Использует LocalStorage для хранения данных
- Все данные локальные
- Функции парсинга и отправки не работают

#### 2. Connected режим (с расширением)
- Синхронизация с Chrome Extension
- Полный функционал
- Данные синхронизируются

### Синхронизация данных

Дашборд и расширение используют одинаковую структуру данных:

```javascript
{
  leads: {
    "username": { ...leadData }
  },
  campaigns: {
    "campaignId": { ...campaignData }
  },
  messageHistory: [...],
  settings: { ... }
}
```

## Использование

### 1. Просмотр статистики

Откройте дашборд → вкладка **Overview**

Вы увидите:
- Общее количество лидов
- Активные кампании
- Отправленные сообщения
- Success rate

### 2. Управление лидами

**Leads** → Просмотр всех лидов

Действия:
- Поиск по имени/username
- Экспорт в CSV
- Удаление отдельных лидов
- Очистка всей базы

### 3. Создание кампаний

**Campaigns** → + New Campaign

_Примечание: Пока создание кампаний через расширение. Скоро добавим в дашборд!_

### 4. Парсинг лидов

**Scraper** → Настроить параметры → Start Scraping

⚠️ Требуется установленное расширение и открытая страница Instagram.

### 5. Настройки

**Settings** → Изменить параметры → Save

Настройки синхронизируются с расширением.

## Интеграция с расширением

### Автоматическая синхронизация

При наличии расширения данные синхронизируются автоматически:

1. Открыт дашборд
2. Расширение определяется
3. Данные загружаются из расширения
4. Изменения синхронизируются

### Ручная синхронизация

Кнопка **🔄 Sync** в правом верхнем углу.

### Статус подключения

В боковой панели снизу:
- 🟢 Extension: Connected
- 🔴 Extension: Disconnected

## Экспорт/Импорт данных

### Экспорт всех данных

Settings → 📥 Export All Data

Сохраняется JSON файл со всеми данными.

### Импорт данных

Settings → 📤 Import Data → Выбрать JSON файл

Восстанавливаются все лиды, кампании, история.

## Безопасность

### Локальное хранение

Все данные хранятся локально:
- В LocalStorage браузера
- Не отправляются на сервер
- Доступны только вам

### API ключи

OpenAI API ключ хранится:
- В LocalStorage
- Зашифрован в Chrome Extension Storage
- Не передается никуда кроме OpenAI

## Troubleshooting

### Расширение не определяется

1. Убедитесь что расширение установлено
2. Проверьте chrome://extensions/
3. Обновите страницу дашборда
4. Кликните "🔄 Sync"

### Данные не синхронизируются

1. Откройте расширение
2. Проверьте что есть данные
3. В дашборде кликните "🔄 Sync"
4. Проверьте консоль (F12) на ошибки

### Парсинг не работает

Парсинг работает только через расширение:
1. Установите расширение
2. Откройте Instagram
3. В дашборде нажмите "Start Scraping"
4. Расширение выполнит парсинг
